# VulnGuard Development Roadmap

## Phase 0 — Requirements and architecture
Requirements, threat model, environment, project structure, initial GitHub repo.

## Phase 1 — Environment and tooling verification
Confirm reproducible Python, Node.js, Git, and container tooling.

## Phase 2 — Repository structure and development standards
Establish application directories, linting, formatting, and contribution rules.

## Phase 3 — FastAPI foundation
Application settings, API versioning, health endpoints, and error handling.

## Phase 4 — Database
Models, migrations, repository layer, and initial data tests.

## Phase 5 — Authentication and authorization
Secure identity, roles, sessions, and resource ownership.

## Phase 6 — Frontend foundation
React layout, routing, reusable UI, and API client.

## Phase 7 — Repository integration
Authorized repository registration and GitHub metadata.

## Phase 8 — Background scan jobs
Queue, worker, progress, timeouts, and failure handling.

## Phase 9 — Scanner framework
Common execution interface and validated output handling.

## Phase 10 — Semgrep integration
Source-code security scanning.

## Phase 11 — Trivy dependency scanning
Known vulnerability detection in supported dependencies.

## Phase 12 — Gitleaks integration
Secret detection and redaction.

## Phase 13 — Container and IaC scanning
Image and infrastructure configuration findings.

## Phase 14 — Unified findings
Normalization, deduplication, fingerprints, and history.

## Phase 15 — Dashboard integration
Real scan data, finding detail views, and filtering.

## Phase 16 — Risk engine
Transparent contextual risk assessment.

## Phase 17 — AI assistant
Optional local explanations and remediation suggestions.

## Phase 18 — Remediation validation
Fix workflow and rescanning.

## Phase 19 — Attack-path graph
Evidence-backed graph relationships and visualization.

## Phase 20 — CI/CD policies
Configurable gates and GitHub Actions checks.

## Phase 21 — Reports and audit
Export, notifications, history, and auditability.

## Phase 22 — Testing and evaluation
Unit, integration, end-to-end, security, and performance testing.

## Phase 23 — Hardening
Worker isolation, application security, dependency checks, and CI.

## Phase 24 — Deployment and submission
Reproducible deployment, documentation, results, and presentation.
